# Research prompt

Copy the following into the intended session and replace placeholders.

```text
Read AGENTS.md and docs/workflow.md. You are the research/planning session for THIS event repository. Use my own authorized GitHub account for remote actions. Do not start implementation or other sessions.

Event/rules links: [provide]
Available time, deadline/timezone, team/session capacity: [provide]
Ideas/interests/constraints/budget: [provide, or ask me]

Research the event, tracks, judging criteria, promising approaches, and risky integrations using current primary sources. Record evidence and assumptions in docs/research.md and fill docs/brief.md. Ask me for the key product choice if no direction is selected. Recommend a feasible MVP, explicit non-goals, demo journey, and fallback.

After scope is agreed, inspect existing issues and create draft tickets using tasks/TEMPLATE.md. Include foundation, bounded core features, integration/demo, and optional stretch only where useful. Include dependencies and acceptance criteria. Leave phase/task ID allocation for the next organization step. Do not duplicate existing tickets. Commit planning docs on a planning branch and open a PR. Return issue links, open decisions, risks, and the planning PR. Do not merge until asked.
```
